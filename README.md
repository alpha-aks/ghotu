# Gyuto Tantric Monastery Website

Official website for **Gyuto Tantric Monastery (དཔལ་ལྡན་རྒྱུད་སྟོད་གྲྭ་ཚང་།)** located in Sidhbari, Dharamshala, Himachal Pradesh, India.

## Features
- **Bilingual Interface**: Full support for English and Tibetan (བོད་ཡིག).
- **Home Page**: Monastic history, leadership, daily pujas & events, departments, and visitor announcements.
- **Contact Us**: Address, monastery direct email, phone, social links, and Google Map location.
- **Support Us**: Donation portal with recurring/one-time donation frequency, donation amounts, transaction fee coverage, and "Before You Attend" monastery guide.
- **Responsive & Modern**: Designed to match high-fidelity monastic Figma specifications with Cormorant Garamond serif headings, traditional maroon and gold colors, and Lucide icons.

## Tech Stack
- React 19
- Vite
- Lucide React
- CSS3 Design System

## Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
